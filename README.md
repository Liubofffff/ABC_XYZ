#ABC-XYZ-анализ товаров

Описание проекта

Проект посвящен проведению многомерного ABC-XYZ-анализа товарного ассортимента с использованием Google Sheets.

Анализ выполнен на данных о продажах товаров и позволяет оценить ассортимент одновременно по нескольким ключевым параметрам:

количеству проданных единиц;
сумме продаж с учетом скидки;
месячной оборачиваемости;
стабильности спроса.
В результате для каждого товара сформирована комбинированная категория ABC-XYZ, позволяющая оценить не только объем и финансовый вклад позиции, но и предсказуемость спроса.

Цель проекта
Провести многомерный ABC-анализ по трем признакам:

Количество проданных единиц.
Сумма продаж с учетом скидки.
Месячная оборачиваемость.
Дополнить ABC-анализ XYZ-классификацией на основе стабильности продаж каждого товара.

Основная цель — получить инструмент для принятия решений по ассортименту, ценообразованию, выкладке товаров, стимулированию продаж и управлению запасами.

Бизнес-задача
ABC-анализ позволяет определить, какие товары формируют основной объем продаж, выручки и потенциальной оборачиваемости.

XYZ-анализ дополняет эту информацию оценкой стабильности спроса:

товары категории X имеют стабильные продажи;
товары категории Y характеризуются умеренной вариативностью спроса;
товары категории Z имеют высокую вариативность продаж.
Совместный анализ позволяет определить товары, которые одновременно:

хорошо или плохо продаются;
формируют высокий или низкий денежный результат;
имеют высокую или низкую оборачиваемость;
характеризуются стабильным или нестабильным спросом.

Анализ: ABC / XYZ
Визуализация и агрегация: сводные таблицы
Основные расчеты: формулы Google Sheets

Подготовка данных
Для проведения анализа в исходную таблицу добавлены два расчетных поля.

DR_CSales — сумма продаж
Рассчитывается как:

Количество проданных единиц × стоимость одной единицы товара

DR_CSalesDisc — сумма продаж с учетом скидки
Рассчитывается как:

Сумма продаж − размер скидки

Именно показатель DR_CSalesDisc используется в дальнейшем для ABC-анализа по сумме продаж.

Важно: скидка DR_SDisc применяется к итоговому количеству товара, а не к каждой проданной единице. Поэтому DR_SDisc не умножается на DR_Kol.
Структура проекта
Для проведения анализа используются отдельные листы Google Sheets:

Свод — агрегация исходных данных;
Исходник — подготовленная таблица для ABC-анализа;
ABC — расчет ABC-классификации;
XYZ — расчет стабильности продаж;
ABC-XYZ — объединение результатов двух анализов;
ИТОГ — сводная таблица по итоговым группам.
ABC-анализ
ABC-анализ проводится одновременно по трем показателям:

количество проданных товаров;
сумма продаж с учетом скидки;
месячная оборачиваемость.
1. Количество проданных товаров
На листе ABC товары сортируются по убыванию количества проданных единиц.

Для каждой позиции рассчитываются:

доля товара в общем объеме продаж;
накопленная доля;
ABC-категория.
Границы категорий:

A — 0–79%;
B — 80–94%;
C — 95–100%.
2. Сумма продаж
Аналогичный расчет выполняется по сумме продаж с учетом скидки.

Для каждого товара определяется его вклад в общую сумму продаж и присваивается категория:

A — 0–79%;
B — 80–94%;
C — 95–100%.
3. Месячная оборачиваемость
Месячная оборачиваемость рассчитывается по формуле:

Среднедневное количество продаж × 30 дней

Среднедневное количество продаж:

Количество проданных товаров / количество дней в периоде

Показатель показывает, сколько единиц товара потенциально может быть продано за месяц при сохранении текущего среднего темпа продаж.

Для месячной оборачиваемости также выполняется ABC-классификация по границам:

A — 0–79%;
B — 80–94%;
C — 95–100%.
Многомерный ABC-анализ
После проведения трех отдельных ABC-анализов категории объединяются.

Каждому товару присваивается трехсимвольная группа:

ABC по количеству + ABC по сумме продаж + ABC по оборачиваемости

Например:

AAA — товар относится к категории A по всем трем показателям.

CCC — товар относится к категории C по всем трем показателям.

Таким образом, многомерный анализ позволяет увидеть не только общий объем продаж, но и сопоставить его с денежным вкладом и потенциальной оборачиваемостью товара.

XYZ-анализ
XYZ-анализ проводится для оценки стабильности спроса на товары.

Для каждого товара рассчитывается количество проданных единиц по каждому дню периода.

Далее определяется количество дней, в которые товар фактически продавался.

Минимальное количество дней
Если товар продавался менее чем 3 дня, провести корректный XYZ-анализ невозможно.

Для таких позиций формируется отдельная категория:

«Группу по XYZ оценить невозможно»

Коэффициент вариации
Для товаров, которые продавались минимум 3 дня, рассчитывается коэффициент вариации:

Коэффициент вариации = стандартное отклонение / среднее количество продаж

Чем ниже коэффициент вариации, тем стабильнее спрос.

XYZ-классификация
Используются следующие границы:

X — 0–9%;
Y — 10–24%;
Z — 25–100%.
Интерпретация категорий:

X — стабильный спрос, продажи относительно предсказуемы.

Y — умеренная вариативность спроса, возможны колебания продаж.

Z — высокая вариативность спроса, продажи нестабильны и хуже прогнозируются.

Объединение ABC и XYZ
На листе ABC-XYZ объединяются результаты:

многомерного ABC-анализа;
XYZ-анализа.
В результате каждый товар получает итоговую классификацию.

Например:

AAAX — высокая значимость товара по всем ABC-показателям и стабильный спрос;
BBBY — средний вклад по ABC-показателям и умеренная вариативность;
CCCZ — низкий вклад по всем ABC-показателям и нестабильный спрос.
Для товаров, продавшихся менее 3 дней, вместо XYZ-категории указывается:

«Группу по XYZ оценить невозможно».

Итоговая аналитика
На листе ИТОГ формируется сводная таблица с количеством товаров в каждой группе многомерного ABC-анализа.

Отдельно анализируется распределение товаров по XYZ-категориям.

По результатам анализа можно определить:

количество товаров в каждой ABC-группе;
наиболее и наименее значимые товарные позиции;
долю товаров с высокой стабильностью спроса;
количество товаров с нестабильными продажами;
количество позиций, для которых недостаточно данных для XYZ-классификации.
Результаты анализа
В ходе анализа выявлен ряд особенностей товарного ассортимента.

1. Значительная доля товаров категории CCC
В категории CCC выявлено 78 товарных позиций.

Это товары с:

низким количеством продаж;
низким вкладом в выручку;
низкой месячной оборачиваемостью.
Такие позиции требуют дополнительного анализа с точки зрения экономической целесообразности их дальнейшего присутствия в ассортименте.

2. Поштучные продажи отдельных товаров
Часть товаров категории CCC продавалась практически поштучно.

Для таких позиций можно рассмотреть возможность:

перехода от поштучной продажи к продаже упаковками;
изменения формата предложения;
формирования комплектов;
стимулирования покупки большего количества единиц.
Это может увеличить сумму одной продажи и улучшить показатели оборачиваемости.

3. Работа с выкладкой
Для товаров с низким объемом продаж целесообразно проверить их фактическое присутствие и расположение на витрине.

Возможные меры:

перенести товар в более заметную зону;
разместить товар возле кассы;
использовать дополнительные рекомендации продавцов;
проверить наличие товара на витрине.
4. Скидки и акции
Для товаров с низким количеством продаж можно дополнительно проанализировать маржинальность.

Если маржинальность позволяет, потенциальными инструментами увеличения продаж могут стать:

скидки;
акции;
специальные предложения;
комплекты;
кросс-продажи.
5. Работа с ценой
Для товаров со средним и высоким количеством продаж, но относительно небольшой суммой продаж, можно рассмотреть возможность корректировки цены.

Особенно это актуально для позиций с низкой маржинальностью.

Перед изменением цены необходимо дополнительно оценить:

текущую маржинальность;
ценовую эластичность;
конкурентные цены;
влияние изменения цены на объем продаж.
6. Ограничения XYZ-анализа
По результатам анализа все позиции либо характеризуются высокой вариативностью продаж, либо для них невозможно провести полноценный XYZ-анализ из-за недостаточного количества дней продаж.

Это означает, что спрос по рассматриваемому ассортименту в анализируемом периоде нельзя считать стабильно прогнозируемым.

Для повышения качества XYZ-анализа целесообразно использовать более продолжительный период наблюдения.

Бизнес-рекомендации
Для товаров CCC
Провести ревизию ассортимента и определить причины низких продаж:

низкий спрос;
неудобный формат продажи;
недостаточная представленность на витрине;
высокая цена;
отсутствие продвижения.
Для части товаров рассмотреть вывод из ассортимента или изменение формата продаж.

Для товаров с низкой оборачиваемостью
Проверить возможность увеличения продаж за счет:

изменения выкладки;
акций;
скидок;
рекомендаций продавцов;
комплектных предложений.
Для товаров с высоким объемом продаж
Обратить внимание на позиции с высокой оборачиваемостью, но низкой маржинальностью.

Для них целесообразно дополнительно проанализировать возможность:

корректировки цены;
изменения закупочной стоимости;
пересмотра условий поставщика;
увеличения маржи.
Для нестабильных товаров
Товары категории Z требуют более осторожного управления запасами, поскольку их продажи сложнее прогнозировать.

Для таких позиций необходимо учитывать:

колебания спроса;
сезонность;
акции;
единичные крупные продажи;
особенности клиентского поведения.
Для товаров без XYZ-классификации
Для позиций, продававшихся менее трех дней, рекомендуется накопить больше данных перед принятием решений о стабильности спроса.

Итог
ABC-XYZ-анализ позволяет перейти от простой оценки объема продаж к комплексному анализу товарного ассортимента.

В рамках проекта каждый товар оценивается одновременно по:

количеству продаж → сумме продаж → месячной оборачиваемости → стабильности спроса.

Такой подход позволяет выявить товары, которые формируют основной вклад в бизнес, определить низкоэффективные позиции и сформировать основу для управленческих решений в области:

ассортиментной политики;
ценообразования;
управления запасами;
выкладки товаров;
проведения акций;
оптимизации ассортимента.
Проект демонстрирует применение Google Sheets для проведения многомерного ABC-XYZ-анализа и преобразования операционных данных о продажах в аналитический инструмент для принятия бизнес-решений.
